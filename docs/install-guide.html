Goblin Overlay

Setup in Streamlabs Desktop · about 3 minutes

1Overlay

  1. Sources → + → Browser Source
  2. URL: https://pdbultoc.github.io/goblin-overlay/overlay.html
  3. Width 1920, Height 1080
  4. Untick Shutdown source when not visible
  5. Drag it above your game capture

2Panel

  1. Layout Editor → drag Website into a slot
  2. URL: https://pdbultoc.github.io/goblin-overlay/panel.html
  3. Save

3Use

  • Switch each box on/off in the panel
  • Showmatch: series → Use current opponent
  • monk → Start / Stop

!Fix

  • Nothing shows: source Properties → Refresh cache of current page
Enjoy, Goblin!
