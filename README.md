# SwedishGoblin OBS overlay
Static site: `overlay.html` is the OBS browser source (1920x1080, transparent), `panel.html` is the OBS custom browser dock that switches modules on/off. No build step. Tests: `npm test` (Node 24). Local preview: `python -m http.server 8793` in this folder, then open http://localhost:8793/harness.html.
